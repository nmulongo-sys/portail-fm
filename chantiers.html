Deux achèvements différents. Fait dans le dépôt — le code existe, les tests passent, le commit est nommé : c'est dans le fichier, la case est verrouillée. Case cochée — ce qui se fait hors dépôt, une écoute tranchée, un arbitrage rendu : ça reste dans ce navigateur (fm.chantiers.v1) et ne suit pas d'un appareil à l'autre. Si un item disparaît ou change de place, sa coche est purgée et signalée. Rien n'est envoyé nulle part.
